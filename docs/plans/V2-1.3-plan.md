## 1. Architectural Scope & Contract

- **Goal**: Enable under-5-minute local onboarding mirroring production mechanics: local PostgreSQL 16 catalog on port 5433 + remote GCS Parquet streaming authenticated via Google Cloud Application Default Credentials (ADC) with zero hardcoded secrets.
- **Port Binding**: Local PostgreSQL binds to `127.0.0.1:5433:5432` to avoid colliding with any host Postgres or the Cube SQL API on port 5432.
- **Auto-Seeding**: Mounts `../ducklake/schema.sql` into `/docker-entrypoint-initdb.d/01_schema.sql` so container startup automatically provisions the DuckLake catalog tables.

## 2. Step-by-Step Implementation Tasks

1. **Author `version-two/infra/docker-compose.dev.yml`**:
   - Service `ducklake-catalog-db` using `postgres:16-alpine`.
   - Port `5433:5432`.
   - Volume mounting `../ducklake/schema.sql:/docker-entrypoint-initdb.d/01_schema.sql:ro`.
   - Healthcheck using `pg_isready -U ducklake_dev -d ducklake_catalog`.

2. **Author `version-two/infra/.env.example`**:
   - Define `DUCKLAKE_DB_URL`, `GCS_BUCKET_NAME`, `CUBEJS_API_SECRET` (placeholder), `CUBEJS_DEV_MODE`, `PORTAL_PORT`, `CUBE_REST_PORT`, `CUBE_SQL_PORT` with zero production secret literals.

3. **Author `version-two/infra/adc_harness.py`**:
   - `locate_adc_file()`: Checks `GOOGLE_APPLICATION_CREDENTIALS` env var and standard gcloud ADC paths (`~/.config/gcloud/application_default_credentials.json`).
   - `verify_adc_credentials(adc_path=None)`: Validates JSON structure (`type` in `authorized_user`, `service_account`, `external_account`, `impersonated_service_account`) without leaking private material.
   - `verify_dev_environment()`: Validates presence of `docker-compose.dev.yml`, `.env.example`, and catalog schema mount.

4. **Author `version-two/tests/test_v2_1_3_local_dev_harness.py`**:
   - Test 1 (`test_docker_compose_dev_contract`): Verifies `postgres:16-alpine`, port `5433:5432`, `ducklake_catalog`, and `schema.sql` volume mount.
   - Test 2 (`test_env_example_completeness_and_zero_secrets`): Verifies required keys exist and no real secrets/passwords are committed.
   - Test 3 (`test_adc_credential_validator`): Tests valid ADC JSON structures and invalid/missing credential rejection.
