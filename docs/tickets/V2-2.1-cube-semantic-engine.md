## Goal
Configure Cube.js 1.7.x with embedded DuckDB via `@duckdb/node-api`, establishing the startup attachment of the DuckLake PostgreSQL catalog (`ATTACH 'ducklake:postgres:...' AS lake`) and enabling high-performance vectorized query execution over GCS.

## Acceptance Criteria
1. Node package manifest installs Cube 1.7.x and `@duckdb/node-api` without deprecated dependencies.
2. `cube.js` initializes in-process DuckDB, installs/loads `httpfs` and `ducklake` extensions at boot.
3. Successfully executes `SELECT count(*) FROM lake.scbi_cdp_mart.cnf__fact_annuity_quotations` directly through the Cube driver.
4. Server starts up cleanly on port 4000 locally and reports healthy status.

## User Stories
1. *As a backend engineer*, I want DuckDB embedded directly inside Cube's process, so that query execution does not suffer inter-process network latency or external daemon crashes.
2. *As a platform operator*, I want Cube to dynamically attach to the DuckLake catalog at boot, so that all table schemas and partition manifests are auto-discovered without hand-written SQL views.

## Seam
Node.js integration test executing a sample query through Cube's driver against embedded DuckDB with DuckLake attached.
