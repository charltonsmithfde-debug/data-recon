## Goal
Rewire Metabase and Power BI DirectQuery connections to point exclusively at the Cube SQL API (Postgres Wire on port 5432), prohibiting direct access to Cloud SQL or raw GCS storage and documenting the IAP TCP tunneling procedure.

## Acceptance Criteria
1. Metabase database connection configured to query `scbi-cube-sql:5432` via internal VPC peering with scrypt-authenticated service credentials.
2. Power BI DirectQuery connection procedure verified over `gcloud compute start-iap-tunnel scbi-cube-sql 5432`.
3. Validates that analytical BI queries resolve against Cube semantic models without bypass.
4. Generates step-by-step connection guide in `docs/METABASE_CUBE_SQL.md`.

## User Stories
1. *As a Power BI report author*, I want to connect to Cube SQL API over an encrypted IAP tunnel, so that I can author DirectQuery reports against central metrics without VPN overhead.
2. *As a Metabase analyst*, I want dashboard cards to execute against Cube semantic definitions, so that results match executive portal numbers exactly.

## Seam
Integration test executing SQL queries via PostgreSQL client (`psql` or `asyncpg`) against port 5432 verifying schema reflection and metric calculation.
