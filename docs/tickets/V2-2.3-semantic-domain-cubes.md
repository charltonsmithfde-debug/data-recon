## Goal
Build comprehensive, validated semantic models for all four core business domains (`AnnuityQuotation.js`, `InvestmentAnalysis.js`, `MemberAnalysis.js`, and `SharedDimensions.js`), establishing accurate multi-table join relationships and pre-aggregations.

## Acceptance Criteria
1. Replaces outdated `cube/model/cubes/*.js` with validated Cube 1.7.x JavaScript models.
2. Fixes legacy column mismatches (e.g., binds `member_age` correctly instead of nonexistent `current_age`).
3. Defines primary facts (`cnf__fact_annuity_quotations`, `cnf__fact_member_investment_aua`) and dimension joins (`dim_member`, `dim_scheme`, `dim_date`).
4. Establishes standard business measures: total AUA, active member count, quotation count, average commission rate.

## User Stories
1. *As an actuarial analyst*, I want accurate Annuity Quotation metrics and dimensions, so that my portfolio reports match verified data warehouse totals.
2. *As a BI developer*, I want clean dimension joins between member demographics and investment accounts, so that I can slice AUA by age bracket and scheme type without manual SQL joins.

## Seam
Cube schema validation suite testing compilation and executing sample queries against all 4 defined domain cubes.
