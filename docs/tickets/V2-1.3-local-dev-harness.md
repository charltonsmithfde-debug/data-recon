## Goal
Provide a turn-key local developer stack with Docker Compose running PostgreSQL on port 5433, configured to mirror Cloud SQL, and wiring Application Default Credentials (ADC) to stream Parquet from GCS without hardcoded credentials.

## Acceptance Criteria
1. `docker-compose.dev.yml` boots PostgreSQL 16 on port 5433 with the DuckLake catalog schema pre-seeded.
2. `.env.example` provides standard local configuration variables with zero secret literals.
3. Automated startup script validates that Google Cloud ADC credentials (`~/.config/gcloud/application_default_credentials.json`) are detected and valid.
4. Total spin-up time for a new engineer is under 5 minutes.

## User Stories
1. *As a newly onboarded developer*, I want a one-command `docker compose up` command, so that I can begin testing against local catalog metadata without complex GCP cloud infrastructure setup.
2. *As a security engineer*, I want local development to use personal ADC tokens rather than shared service account keys, so that developer access is individually traceable and revocable.

## Seam
Docker Compose healthcheck test verifying local PostgreSQL connection and catalog schema presence.
