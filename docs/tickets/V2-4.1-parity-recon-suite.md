## Goal
Establish an automated parity verification test suite that executes identical analytical queries across Cube REST API, Cube SQL API, and direct DuckLake SQL, asserting 100% bit-identical calculation results across all measures and dimensions.

## Acceptance Criteria
1. Test suite samples across all 4 business domains (Annuity, Investment, Member, Shared).
2. Runs 50+ diverse query variations covering single measures, multi-dimensional breakdowns, and complex filter cascades.
3. Compares REST JSON responses against PostgreSQL wire tabular results, asserting exact numeric parity (`delta == 0.0`).
4. Generates an automated reconciliation markdown report in `version-two/tests/reports/parity_report.md`.

## User Stories
1. *As a Chief Analytics Officer*, I want automated proof that Metabase, Power BI, and the Web Portal report identical numbers, so that executive meetings never debate whose report is right.
2. *As a QA engineer*, I want a repeatable regression test suite to catch calculation drift before any semantic model changes reach production.

## Seam
Pytest execution of `test_metric_parity.py` running against local or staging Cube instance.
