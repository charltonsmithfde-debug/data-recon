## Goal
Build a clean, decoupled FastAPI backend for the Thin Web Portal that parses authenticated IAP headers, resolves corporate roles, mints signed HS256 Cube JWTs, proxies requests to Cube REST API, and eliminates all synthetic endpoints.

## Acceptance Criteria
1. Replaces monolithic legacy `thin-web-app/server.py` with modular FastAPI router.
2. Extracts verified user identity from `X-Goog-Authenticated-User-Email` header, rejecting unauthenticated requests with HTTP 401.
3. Mints signed Cube JWT containing verified role and PII permissions from `role_assignments.json`.
4. Replaces synthetic data endpoints (`handle_member_analysis_query`) with live Cube REST queries.

## User Stories
1. *As a portal user*, I want the dashboard to display verified analytical data from Cube, so that I can make business decisions based on real member metrics.
2. *As a security officer*, I want user roles determined by server-side identity verification rather than client UI parameters, so that privileges cannot be escalated.

## Seam
Pytest API test suite verifying IAP header authentication, role assignment lookup, JWT minting, and proxy routing to Cube.
